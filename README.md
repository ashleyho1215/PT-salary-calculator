# 💰 Part-Time Wage & Shift Tracker (Golden Warm Theme)

A simple, efficient, and user-friendly web application designed for part-time workers to log work hours, compute wage breakdowns, manage multiple shift schedules, and check upcoming paydays.

![Node.js](https://img.shields.io/badge/Backend-Node.js-green)
![Express](https://img.shields.io/badge/Framework-Express-lightgrey)
![Database](https://img.shields.io/badge/Database-SQLite3-blue)

---

## ✨ Key Features

- 📅 **Batch Multi-Date Logging**: Add identical shift schedules across multiple dates in just one click.
- ⏱️ **Automatic Overtime Calculation**: Automatically calculates overtime wages (1.34x rate) for work hours exceeding 8 hours per day.
- 💵 **Flexible Fee Breakdown**: Manage hourly rates, labor/health insurance deductions, meal allowances, and transaction fees.
- 🔍 **Payday Quick Reconciliation**: Filter and view total expected earnings for any specific payday.
- 📊 **Excel Export**: Export all work logs into `.xlsx` spreadsheet format for offline accounting.
- ✏️ **Full CRUD Support**: View, edit, or delete work records anytime with modal editing support.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom Responsive Layout), JavaScript (Fetch API)
- **Backend**: Node.js, Express.js
- **Database**: SQLite3
- **Export Tool**: XLSX (`xlsx` npm package)

# 💰 努力打拚薪資與排班管理金庫

一款專為兼職打工族設計的輕量級、高效率 Web 應用程式。基於 Express 與 SQLite 開發，能幫助你輕鬆記錄工作時數、自動計算薪資細項、一次批量建立多天排班，並快速進行發薪日對帳。

![Node.js](https://img.shields.io/badge/後端-Node.js-green)
![Express](https://img.shields.io/badge/框架-Express-lightgrey)
![Database](https://img.shields.io/badge/資料庫-SQLite3-blue)

---

## ✨ 核心特色

- 📅 **多日期批量新增**：針對條件相同的打工活動，只需設定一次薪資與時數，即可點選多個日期一鍵批量生成紀錄。
- ⏱️ **自動計算加班費**：每日工作超過 8 小時的部分，系統會自動以 1.34 倍時薪計算加班費。
- 💵 **靈活的扣款與津貼管理**：支援時薪、勞健保費扣除、餐費補助及轉帳手續費等細項設定。
- 🔍 **發薪日快速對帳**：可依指定發薪日期進行篩選，快速試算當天預計匯入的總薪資金額與明細。
- 📊 **Excel 報表匯出**：支援將所有打工明細一鍵匯出為 `.xlsx` 試算表，方便離線記帳與留存。
- ✏️ **完整 CRUD 編輯支援**：提供彈出式視窗，隨時可對已建立的紀錄進行查看、修改或刪除。

---

## 🛠️ 技術棧

- **前端**：HTML5, CSS3（自訂響應式版面）, JavaScript (Fetch API)
- **後端**：Node.js, Express.js
- **資料庫**：SQLite3
- **匯出工具**：XLSX (`xlsx` npm 套件)
